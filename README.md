# Student Login & Registration System

A small frontend-only educational project for a Software Testing assignment. It uses HTML, CSS, vanilla JavaScript, browser storage, Playwright, and an Azure DevOps Pipeline.

## Features
- Student registration with name, email, and password fields
- Basic client-side validation for required fields, email format, and password length
- Duplicate email check
- Login and logout
- Student dashboard
- Demo login account
- Six Playwright automated tests
- JUnit and HTML test reports
- Azure Pipeline configuration

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- localStorage and sessionStorage
- Playwright Test
- http-server
- Azure DevOps Pipelines

## Requirements
Install Node.js LTS (Node.js 22 or newer recommended) and VS Code.

## Run locally
Open a terminal in the project folder and run:

```powershell
npm install
npx playwright install chromium
npm start
```

Open http://127.0.0.1:4173 in a browser. Keep the terminal running while using the site.

## Demo account
- Email: `demo@student.com`
- Password: `Student123`

## Run automated tests
Open a second terminal in the project folder and run:

```powershell
npm test
```

View the HTML report:

```powershell
npm run test:report
```

The report is generated in `playwright-report`. JUnit results are generated in `test-results/junit.xml`.

## Important limitation
This is a frontend-only teaching demo. Account information is stored in browser localStorage, including passwords in plain text. It is not secure authentication and must not be used for real accounts or real personal information. There is no backend or database.
